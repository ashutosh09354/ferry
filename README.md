# Ferry — React + JavaScript + Tailwind

From-scratch responsive ferry booking frontend.

## Run
npm install
npm run dev

## Build
npm run build

## Main routes
/, /routes, /schedule, /experiences, /search, /ferry/sea-link-express, /passenger, /payment, /confirmation, /ticket, /bookings, /login, /register, /profile, /settings, /help

The layout uses full browser width with a max-width content container only for readable content; full-bleed hero/footer sections span the viewport.
